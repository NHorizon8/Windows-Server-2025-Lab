**1. Create a New Virtual Machine**  
Start VMware Workstation and select **Create a New Virtual Machine**.

**2. Choose Configuration Type**  
Select **Custom (Advanced)** to control the VM hardware and storage settings.

**3. Easy Install / OS Selection**  
Select the **Windows Server 2025 ISO** and choose **Windows Server 2025 Datacenter**.

**4. Name & Location**  
Name the VM **Windows Server 2025** and store its VM files on the **dedicated secondary HDD partition**.

**5. Firmware Type**  
Select **UEFI** for the modern Windows Server 2025 installation. Keep Secure Boot disabled for this initial lab.

**6. Processor Configuration**  
Configure **1 processor × 2 cores (2 vCPUs)** — enough for the Server VM while preserving CPU resources for the host and future VMs.

**7. Memory for the Virtual Machine**  
Allocate **6 GB RAM (6144 MB)** — a practical balance for Windows Server and future server roles.

**8. Network Type**  
Select **NAT** to provide Internet connectivity through the host while keeping the VM on VMware's virtual network.

**9. SCSI Controller Type**  
Select **LSI Logic SAS**, which VMware recommends for this Windows Server 2025 configuration.

**10. Virtual Disk Type**  
Select **NVMe (Recommended)** — this is the VM's virtual disk interface and is independent of the physical HDD storing the VM files.

**11. Select a Disk**  
Choose **Create a new virtual disk** so the Server gets its own virtual hard disk instead of directly accessing a physical disk.

**12. Specify Disk Capacity**  
Set **60 GB maximum capacity**, keep **Allocate all disk space now** disabled, and **store the virtual disk as a single file**.

**13. Installation Starts**  
Finish the wizard. VMware creates the configured VM and **Easy Install begins the Windows Server 2025 installation**, including the automatic restarts required during setup.
